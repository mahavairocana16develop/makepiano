# makepiano

YouTube の URL からピアノ譜（PDF / MIDI / MusicXML / SVG）を自動生成するツール。
[klang.io](https://studio.klang.io/) のようなことをローカルで行います。

## 仕組み

1. **yt-dlp** で YouTube から音声を取得
2. （任意）**Demucs** で音源分離し、ボーカル・ドラム・ベースを除去 or ピアノ成分だけ抽出
3. **ByteDance の piano_transcription_inference**（ピアノ専用の高精度モデル）で音声 → MIDI
4. **librosa** でビート追跡してテンポ推定・小節割り（テンポ揺れにも追従）
5. **music21** で左手/右手に分割・クオンタイズ・調判定して MusicXML 化
6. **verovio** で楽譜を SVG にレンダリング、**cairosvg** で PDF 化

MuseScore などの外部アプリは不要です。

## セットアップ

```bash
brew install ffmpeg cairo   # 未インストールの場合
uv sync
```

初回実行時に採譜モデル（約172 MB）を `~/piano_transcription_inference_data/` にダウンロードします。

## 使い方

### CLI

```bash
uv run makepiano "https://www.youtube.com/watch?v=..."
```

出力は `output/<動画タイトル>/` に保存されます:

| ファイル | 内容 |
|---|---|
| `stems/<種類>/original/score.pdf` | ピアノ譜（オリジナル） |
| `stems/<種類>/intermediate/score.pdf` | ピアノ譜（中級アレンジ） |
| `stems/<種類>/beginner/score.pdf` | ピアノ譜（初級アレンジ） |
| `stems/<種類>/*/score.musicxml` | MuseScore 等で編集可能な楽譜データ |
| `stems/<種類>/*/svg/page-NNN.svg` | ページごとの楽譜画像 |
| `stems/<種類>/*/playback.json` | Web UI の再生同期用データ |
| `stems/<種類>/transcription.mid` | 採譜結果の MIDI（演奏タイミングそのまま） |
| `stems/<種類>/source.wav` | 採譜に使った音声（`rescore` 用） |
| `source_mix.wav` | ダウンロードした元音声 |

主なオプション:

| オプション | 説明 |
|---|---|
| `--stem all` | 作成する音源の種類（既定 all）。`none,other` のようにカンマ区切りで絞れる |
| `--bpm 120` | ビート追跡を使わず固定テンポにする |
| `--beats-per-bar 3` | 拍子（3 = 3/4） |
| `--grid 2` | 最小音価（2=8分, 4=16分, 3=3連） |
| `--split 60` | 左右の手を分ける MIDI ノート番号（60 = 中央ド） |
| `--beat-offset 1` | 小節線を N 拍ずらす（小節の頭がずれているとき） |
| `--min-velocity 25` | この音量未満の音を捨てる |
| `--max-pitch 96` | この高さ（MIDI ノート番号）より上の音を捨てる。歌・シンバルの混入対策 |
| `--min-note-ms 60` | これより短い音を捨てる（採譜ノイズ対策） |
| `--level both` | 生成する難易度（既定 both = 全部）。中級は右手メロディ＋拍頭にコード構成音（最大 2 音）、左手はルートと 5 度を 1 拍ずつ交互。初級は右手メロディのみ、左手はルート音を 2 拍ごと。どちらも最小音価 8 分 |
| `--max-notes 5` / `--max-span 12` | 弾ける範囲の制限：各手の同時発音数と手の広がり（半音）。右手は収まらない低い音を左手へ回し、左手は収まらない高い音を捨てる |
| `--force` | 既存ジョブとキャッシュを無視して分離・採譜からやり直す |
| `--triplets 16th` | 拍ごとに三連符を自動検出（off / 8th / 16th）。スウィングや三連の曲で打鍵タイミングの再現性が大きく上がる |
| `--no-pedal-marks` / `--no-dynamics` | ペダル記号 / 強弱記号を付けない |
| `--no-legato` | 音を次の和音まで伸ばさず、実測の長さで書く |
| `--no-chords` | コードネームを付けない |

### ボーカル入り・バンド音源から伴奏を取り出す

既定では 4 種類すべてを 1 回の処理で作り、Web UI の結果画面で切り替えられます。時間を節約したいときは絞ります。

```bash
uv run makepiano "https://www.youtube.com/watch?v=..." --stem none,other
```

| `--stem` | 内容 | 向いている音源 |
|---|---|---|
| `none` | 分離しない | ピアノソロ |
| `other` | ボーカル・ドラム・ベースを除去した残り（htdemucs） | ピアノ伴奏の弾き語り・バンド曲。まずはこれ |
| `piano` | ピアノ成分だけ抽出（htdemucs_6s） | ギターやシンセも混ざるとき。分離品質はやや不安定 |
| `no_vocals` | ボーカルだけ除去 | ピアノ＋歌 |

初回はモデル（80〜90 MB）をダウンロードします。分離モデルは種類ごとではなく 2 回（htdemucs / htdemucs_6s）だけ実行します。全種類作ると CPU で曲の長さの 3〜4 倍程度かかります。

採譜をやり直さずに、設定を変えて楽譜だけ作り直す:

```bash
uv run makepiano rescore "output/<動画タイトル>" --beats-per-bar 3 --grid 2
```

### 合成比較による採譜の最適化（既定でオン）

採譜モデルの推論は 1 回だけ行い、その生出力（打鍵・持続・ペダルの確率）を複数のしきい値で MIDI 化した候補を、
ブラウザと同じピアノ音源（MusyngKite）でサーバー側にレンダリングし、採譜に使った音声と比較して最も近い候補を採用します。
比較指標は対数メルスペクトログラム距離・打鍵タイミングの一致率・クロマ（和声）の一致率です。
結果は `stems/<種類>/refine.json`（採用した設定と全候補の採点）に記録されます。
`--no-refine`（Web では詳細設定のチェックを外す）で省略できます（39 秒の曲で約 20 秒の追加）。

### キャッシュと再利用

- ダウンロードした音声は動画 ID をキーに `output/_cache/<動画ID>.wav` に保存され、同じ動画は再ダウンロードしません。
- 同じ動画のジョブが既にあれば（各ジョブの `job.json` で照合）、そのフォルダを更新します。音源分離と採譜は作成済みの種類をそのまま再利用し、未作成の種類だけ追加します。楽譜化は設定変更を反映するため毎回やり直します（数秒）。
- 全部やり直したいときは `--force`（Web UI では詳細設定の「作り直す」）。

### ローカルの動画・音声ファイルから

画面収録（.mov / .mp4）や音声ファイルもそのまま渡せます。

```bash
uv run makepiano ~/Desktop/画面収録.mov --stem other
```

### Web UI

```bash
uv run makepiano-web
```

http://127.0.0.1:8000 を開き、URL を貼って「楽譜を作る」。
PDF / MIDI / MusicXML のダウンロードと、次のプレビュー・再生機能が使えます。

- **プログレスバー**：処理段階（取得→分離→採譜→最適化→楽譜化）と残り時間の目安を表示。曲の長さと処理内容から見積もり、進行に応じて実測で補正します
- **音源の種類・難易度の切り替え**：作成済みの音源種類 × オリジナル / 中級 / 初級を結果画面でいつでも切り替え（再生位置とモードは維持）
- **シートビュー**：楽譜。再生中は鳴っている音符が赤くハイライトされ、自動スクロールします
- **ピアノビュー**：88 鍵の鍵盤と落下ノート表示（右手＝青、左手＝緑）。楽譜と同じ量子化済みノートを表示します
- **再生モード**（既定はシンセ、音源は「伴奏のみ」が既定）：「オリジナル サウンド」（元音声）、「分離後の伴奏」（音源分離した場合）、「シンセサイザー サウンド」（採譜結果をブラウザ内のピアノ音源で演奏）
- シンセ再生は「演奏データ」（採譜した演奏そのもの / 表示中の楽譜どおり）と「テンポ」（元音源に合わせる / 一定）を選べます。中級・初級ではアレンジに対応する演奏がないため楽譜どおりになります。楽譜どおりでも同じ音源チェーンにわずかな揺らぎと音のつながりを加えて自然に鳴らします
- シンセ再生は元音声の平均音量に自動で合わせます。残響スライダーもあります
- **小節リピート**：小節番号を指定（または楽譜上の小節をクリック：1 回目=開始、2 回目=終了）して範囲を繰り返し再生。どの再生モードでも有効
- 再生速度 0.5x〜1.25x、シーク、Space キーで再生/停止
- 「過去の結果を開く」で `output/` にある生成済みの結果を再採譜なしで開けます（サーバー再起動後も可）

コードを変更した場合、HTML（`makepiano/static/index.html`）はページの再読み込みだけで反映されます。Python 側の変更は `makepiano-web` の再起動が必要です。

再生用データは `playback.json`（ノート一覧と、楽譜要素↔秒のタイムマップ）と `audio_original.m4a` / `audio_stem.m4a` に保存されます。

## 制限・注意

- ピアノ専用モデルのため、歌やバンド音源はそのままだと精度が落ちます。`--stem other` で分離してから採譜してください。
- 拍子は自動判定しません（デフォルト 4/4）。ワルツなどは `--beats-per-bar 3` を指定してください。
- ルバートの強い演奏ではリズムが不正確になります。`--bpm` で固定テンポにすると改善することがあります。
- 各手は「同時に鳴り始めた音 = 和音」として単声で記譜し、既定では次の和音まで音を伸ばします（ポップス譜風）。明らかに短く弾かれた音は短いまま書きます。和音は各手 5 音・1 オクターブ以内に収めます。
- 採譜したペダル操作は Ped./＊ として、強弱は小節ごとの平均から pp〜ff として記譜します。「楽譜どおり」再生はこれらを反映します。
- コードネームは構成音からの推定です。テンションや転回形は簡略化されます。
- 処理時間は Apple Silicon の CPU で 4 分の曲あたり 1 分程度です。
